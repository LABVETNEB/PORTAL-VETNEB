## API y responsabilidades

`AdvancedFilterSheet({ open, onOpenChange, title, description?, children, actions?, initialFocusRef?, returnFocusRef?, fallbackFocusRef?, closeLabel? })`. Cada acción opcional (`apply`, `clear`, `cancel`) exige su label y callback; el componente nunca cierra, limpia ni aplica por cuenta propia. Escape, overlay y el botón explícito comunican `onOpenChange(false)`. El foco inicial va al ref operable, primer control del cuerpo o botón de cierre; al cerrar vuelve al trigger operable o al fallback indicado. Un trigger retirado usa el fallback. Un consumidor futuro debe definir draft, estado aplicado, semántica de cerrar/cancelar, validación, disabled/loading/error, navegación y paginación según su contrato S1–S7, y probarlos antes de adoptar.

## Corrección P2 de foco inicial en PR #1868

El review detectó que el primer `input[type="hidden"]` del cuerpo podía ser elegido por el selector de foco antes que un control visible. `focus()` no transfería el foco al input oculto, pero el handler ya había cancelado el autofocus de Radix. Un E2E nuevo reprodujo RED en Chromium con `next start`, apertura por teclado y `initialFocusRef` ausente: el control visible quedó inactivo.

La selección ahora excluye inputs ocultos, controles deshabilitados, destinos con `tabIndex` negativo y elementos ocultos por estilo, `hidden`, `inert` o `aria-hidden` en sus ancestros. Prioriza un `initialFocusRef` válido dentro del diálogo, respeta el orden de tabulación de los candidatos del cuerpo y recurre al botón Cerrar cuando no hay ninguno. El handler cancela el autofocus de Radix sólo después de confirmar la transferencia efectiva. No cambia el estado controlado, las acciones, Escape ni la restauración al cerrar.

El E2E P2 cubre input oculto antes de input o select, disabled, ocultamiento por CSS o ancestros, `inert`, orden de tabulación, ref válido e inválido, fallback y reapertura. Pasó GREEN y falló de nuevo al introducir temporalmente una mutación que admitía el input oculto; la corrección se restauró y C12 completo pasó 14/14 bajo `next start` con un worker, sin retries ni traces. El censo canónico de `frontend/e2e/**` pasó de 55.002 a 55.033 LOC: +31 líneas, techo 68.522 y margen 13.489. La cantidad de specs sigue en 113; ledger, pisos y tolerancias permanecen intactos.
